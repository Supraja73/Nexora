Linux Kernel Isolation Architecture: Containers vs Virtual Machines

A container is not a virtual machine. While a virtual machine emulates physical hardware and boots a completely separate guest kernel via a hypervisor, containers execute natively on the host Linux kernel. The kernel partitions resources using 7 fundamental Namespaces and restricts hardware utilization using Control Groups (cgroups).
